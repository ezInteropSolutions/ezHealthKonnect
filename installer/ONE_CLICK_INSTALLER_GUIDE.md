# One-Click Windows Installer — Build Guide for LLMs

This document teaches an LLM how to build a single self-contained Windows `.exe` installer
for any Node.js + PostgreSQL application, using the pattern proven in ezHealthKonnect.
Reference implementation: `installer/` in the ezHealthKonnect repo.

---

## What We Are Building

A single `AppName-Setup-Win64.exe` that:
- Contains the entire app bundle baked inside it (Go `//go:embed`)
- Installs PostgreSQL silently (winget first, direct download fallback)
- Installs Node.js silently (winget first, direct download fallback)
- Extracts the app to `C:\AppName\`
- Runs `npm install --omit=dev`
- Creates the PostgreSQL database and user
- Runs SQL migrations in correct numeric order
- Registers the app as Windows services (via WinSW)
- Writes a `.env` file with all runtime config
- Adds an uninstall entry to Add/Remove Programs
- **Uninstall** drops the DB/user, stops services, removes all files

## Step 1 — The Embed Pattern (Two Files Required)

**`bundle_windows_embed.go`** — only compiled when `-tags embedded` is passed:
```go
//go:build windows && embedded

package main

import _ "embed"

//go:embed assets/bundle-windows.zip
var embeddedWindowsBundle []byte
```

**`bundle_windows_noembed.go`** — compiled normally (no tags):
```go
//go:build windows && !embedded

package main

var embeddedWindowsBundle []byte
```

The `downloadAppBundle()` function checks `len(embeddedWindowsBundle) > 0` first.
If populated, it writes to a temp file and calls `extractZip(tmp, installDir, true)`.
`stripRoot: true` strips the top-level directory from the zip (e.g. `myapp/` prefix).

## Step 2 — The HTTP Client (CRITICAL — Do Not Skip)

**Problem:** Go's default HTTP client uses HTTP/2. EDB's CDN (PostgreSQL installer)
and some GitHub CDN edges drop large HTTP/2 streams with `INTERNAL_ERROR` after a few MB.

**Fix:** Force HTTP/1.1 for ALL downloads:

```go
import "crypto/tls"

var http1Client = &http.Client{
    Transport: &http.Transport{
        // Empty map = no HTTP/2 upgrades — forces HTTP/1.1 for all TLS connections.
        TLSNextProto:          make(map[string]func(string, *tls.Conn) http.RoundTripper),
        ResponseHeaderTimeout: 60 * time.Second,
    },
}
```

**Fix:** Add retry logic (3 attempts, 4s delay between):
```go
func downloadFileProgress(url, dest string) error {
    const maxAttempts = 3
    var lastErr error
    for attempt := 1; attempt <= maxAttempts; attempt++ {
        if attempt > 1 {
            emit("warn", fmt.Sprintf("  Retrying (%d/%d): %v", attempt, maxAttempts, lastErr))
            time.Sleep(4 * time.Second)
        }
        lastErr = downloadOnce(url, dest)
        if lastErr == nil {
            return nil
        }
    }
    return lastErr
}

func downloadOnce(url, dest string) error {
    req, _ := http.NewRequest("GET", url, nil)
    req.Header.Set("User-Agent", "AppName-Installer/1.0")
    resp, err := http1Client.Do(req)
    // ... write to file with progress reporting every 5s
}
```

## Step 3 — PostgreSQL Installation Strategy

**Try winget first** (available on all Windows 10 1709+ and Windows 11):
```go
func installPostgres() (string, error) {
    if p := findPsql(); p != "" {
        emit("info", "PostgreSQL already installed: "+p)
        return p, nil
    }

    // winget is faster, more reliable, no HTTP/2 issues
    if err := installViaWinget("PostgreSQL.PostgreSQL.15", "PostgreSQL 15"); err == nil {
        time.Sleep(10 * time.Second)
        exec.Command("net", "start", "postgresql-x64-15").Run()
        if p := findPsql(); p != "" {
            return p, nil
        }
    }

    // Fallback: direct EDB download (~350 MB)
    return installPostgresDirect()
}

func installViaWinget(packageID, displayName string) error {
    winget, err := exec.LookPath("winget")
    if err != nil {
        return fmt.Errorf("winget not found")
    }
    cmd := exec.Command(winget, "install", "-e",
        "--id", packageID,
        "--accept-source-agreements",
        "--accept-package-agreements",
        "--silent",
    )
    return streamCmd(cmd)
}
```

Node.js winget ID: `OpenJS.NodeJS.LTS`
PostgreSQL 15 winget ID: `PostgreSQL.PostgreSQL.15`

**Direct download URL for PostgreSQL 15 (fallback):**
```
https://get.enterprisedb.com/postgresql/postgresql-15.13-1-windows-x64.exe
```
Silent install flags: `--mode unattended --unattendedmodeui none --superpassword postgres --serverport 5432 --servicename postgresql-x64-15 --disable-components stackbuilder`

## Step 4 — Migration Sorting (CRITICAL — Do Not Skip)

**Problem:** `os.ReadDir()` returns files sorted lexicographically (byte order).
The `_` character (ASCII 95) is greater than any digit (48–57).
So `V1__` sorts AFTER `V10__` which sorts AFTER `V100__`.

On a fresh database this means V1 (which creates all base tables) runs LAST —
every ALTER TABLE migration before it fails silently because the tables don't exist yet.

**Fix:** Extract the version integer and sort numerically:
```go
import "sort"
import "strconv"

type mig struct {
    version int
    name    string
}
var migs []mig
for _, e := range entries {
    name := e.Name()
    if !strings.HasPrefix(name, "V") || !strings.HasSuffix(name, ".sql") {
        continue
    }
    vStr := strings.SplitN(strings.TrimPrefix(name, "V"), "__", 2)[0]
    v, err := strconv.Atoi(vStr)
    if err != nil { continue }
    migs = append(migs, mig{v, name})
}
sort.Slice(migs, func(i, j int) bool { return migs[i].version < migs[j].version })

// Now run in order: V1 → V2 → V3 → ... → VN
for _, m := range migs {
    cmd := exec.Command(psql, "-h", host, "-U", user, "-d", db, "-f", filepath.Join(migDir, m.name))
    // suppress "already exists" warnings on re-run — not real errors
}
```

## Step 5 — The .env File

Write absolute paths — never relative. The Go service may start from a different
working directory than expected.

```go
content := fmt.Sprintf(`

DB_PORT=%s
DB_NAME=%s
DB_USER=%s
DB_PASSWORD=%s

SESSION_COOKIE_SECURE=false

`,
    cfg.AppPort, cfg.APIPort,
    cfg.DBHost, cfg.DBPort, cfg.DBName, cfg.DBUser, cfg.DBPassword,

    cfg.InstallDir, cfg.InstallDir,

```

If your app has a schema/asset directory the backend needs at runtime, set it
as an env var pointing to `installDir\schemas` (or equivalent).

## Step 6 — The Uninstall Flow

The uninstaller must clean up in this order:

1. Stop + remove Windows services (before removing files — WinSW needs the XML config)
2. Terminate active DB connections, drop database, drop user (reads `.env` for credentials)
3. Remove install directory (`os.RemoveAll`)
4. Remove Add/Remove Programs registry key

**Drop database helper:**
```go
func dropDatabaseAndUser(psqlPath, host, port, dbName, dbUser string) error {
    run := func(sql string) error {
        cmd := exec.Command(psqlPath, "-h", host, "-U", "postgres", "-p", port,
            "-d", "postgres", "-c", sql, "-q")
        cmd.Env = append(os.Environ(), "PGPASSWORD=postgres") // superuser password set at install
        out, err := cmd.CombinedOutput()
        if err != nil && !strings.Contains(string(out), "does not exist") {
            return fmt.Errorf("%s", strings.TrimSpace(string(out)))
        }
        return nil
    }
    // Terminate active connections first — DROP DATABASE fails if anyone is connected
    run(fmt.Sprintf(
        `SELECT pg_terminate_backend(pid) FROM pg_stat_activity WHERE datname='%s' AND pid<>pg_backend_pid();`,
        dbName))
    run(fmt.Sprintf("DROP DATABASE IF EXISTS %s;", dbName))
    run(fmt.Sprintf("DROP USER IF EXISTS %s;", dbUser))
    return nil
}
```

**Read credentials from installed .env** (don't trust cfg — user may have changed them):
```go
func loadEnvFile(installDir string) map[string]string {
    result := map[string]string{}
    data, err := os.ReadFile(filepath.Join(installDir, ".env"))
    if err != nil { return result }
    for _, line := range strings.Split(string(data), "\n") {
        if k, v, ok := strings.Cut(strings.TrimSpace(line), "="); ok {
            result[strings.TrimSpace(k)] = strings.TrimSpace(v)
        }
    }
    return result
}
```

## Step 7 — The Build Script (`build-windows-release.ps1`)

The script cross-compiles everything via Docker — no local Go toolchain needed.

```powershell
[CmdletBinding()]
param([switch]$SkipGoCompile)

$RepoRoot    = (Resolve-Path "$PSScriptRoot\..").Path
$DistDir     = Join-Path $RepoRoot "dist"
$AssetsDir   = Join-Path $PSScriptRoot "assets"
$BundleZip   = Join-Path $AssetsDir "bundle-windows.zip"
$CachedGoApi = Join-Path $DistDir "go-api-windows-amd64.exe"  # cache between builds
$TmpDir      = Join-Path $env:TEMP "appname-bundle-$PID"
$BundleDir   = Join-Path $TmpDir "appname"   # this name becomes the zip root (stripped on extract)
```

### Step 1 — Cross-compile the Go backend (or reuse cache)

```powershell
if ($SkipGoCompile) {
    # Copy cached binary — use when only JS/SQL/Node files changed
    Copy-Item $CachedGoApi (Join-Path $BundleDir "go-api.exe") -Force
} else {
    docker run --rm `
      -v "${RepoRoot}:/work" -w /work `
      -e GOOS=windows -e GOARCH=amd64 -e CGO_ENABLED=0 `
      golang:1.25-alpine `
      go build -ldflags "-s -w" -o /work/installer/assets/_go-api-tmp.exe .

    Move-Item (Join-Path $AssetsDir "_go-api-tmp.exe") (Join-Path $BundleDir "go-api.exe") -Force
    Copy-Item (Join-Path $BundleDir "go-api.exe") $CachedGoApi -Force  # save for next time
}
```

**Go version**: check `go.mod` for `go X.Y` directive — use `golang:X.Y-alpine` in Docker.
If wrong version: `go: go.mod requires go >= X.Y (running go Z.W)` error.

### Step 2 — Assemble the bundle (exclude large/unwanted dirs)

```powershell
$ExcludeNames = @('.git','.github','installer','dist','node_modules',
                  'tests','logs','docs','architecture')
# Add any app-specific large directories (e.g. 'schemas', 'downloads', 'data')
```

Copy source files, then copy any required static assets (schemas, fixtures, etc.) separately.

### Step 3 — Zip with correct root directory name

```powershell
Push-Location $TmpDir
Compress-Archive -Path "appname" -DestinationPath $BundleZip -CompressionLevel Optimal
Pop-Location
```

The zip must contain exactly ONE top-level directory (`appname/`).
`extractZip(src, dest, stripRoot: true)` removes that prefix on extraction.

### Step 4 — Cross-compile the installer WITH embedded bundle

```powershell
docker run --rm `
  -v "${RepoRoot}:/work" -w /work/installer `
  -e GOOS=windows -e GOARCH=amd64 -e CGO_ENABLED=0 `
  golang:1.25-alpine `
  go build -tags embedded -ldflags "-s -w -H windowsgui" `
  -o /work/dist/AppName-Setup-Win64.exe .

# Always clean up — bundle-windows.zip is gitignored and gets rebuilt each time
Remove-Item $BundleZip -Force
```

### PowerShell 5.1 Gotchas in the Build Script

- **`$n:` in strings** — `"Step $n: $msg"` fails because PS5.1 reads `$n:` as a PSDrive variable.
  Fix: use `"Step ${n}: $msg"` with braces.
- **`2>&1` on docker** — in PS5.1, redirecting stderr from a native exe creates `NativeCommandError`
  records when `$ErrorActionPreference = 'Stop'`. Use `try { docker info > $null } catch {}` instead.
- **Here-strings for git commit** — use `@'...'@` (single-quoted, no interpolation).
  The closing `'@` must be at column 0.

## Step 8 — The extractZip Helper

```go
func extractZip(src, dest string, stripRoot bool) error {
    r, err := zip.OpenReader(src)
    if err != nil { return err }
    defer r.Close()

    for _, f := range r.File {
        // Windows Compress-Archive uses backslashes — normalise to forward slash
        name := strings.ReplaceAll(f.Name, `\`, `/`)
        if stripRoot {
            idx := strings.Index(name, "/")
            if idx < 0 { continue }
            name = name[idx+1:]
        }
        if name == "" { continue }

        target := filepath.Join(dest, filepath.FromSlash(name))
        if f.FileInfo().IsDir() {
            os.MkdirAll(target, 0755)
            continue
        }
        os.MkdirAll(filepath.Dir(target), 0755)
        // open, create, copy ...
    }
    return nil
}
```

## Step 9 — Windows Service Registration (WinSW)

Download WinSW once at install time (single exe, no zip):
```
https://github.com/winsw/winsw/releases/download/v2.12.0/WinSW-x64.exe
```

Generate an XML config file per service, then run `winsw.exe install`:
```xml
<service>
  <id>myapp</id>
  <name>MyApp</name>
  <description>MyApp Node.js service</description>
  <executable>C:\Program Files\nodejs\node.exe</executable>
  <arguments>C:\MyApp\server.js</arguments>
  <workingdirectory>C:\MyApp</workingdirectory>
  <logpath>C:\MyApp\logs</logpath>
  <log mode="roll-by-size"><sizeThreshold>10240</sizeThreshold><keepFiles>5</keepFiles></log>
  <startmode>Automatic</startmode>
  <env name="NODE_ENV" value="production"/>
</service>
```

## Step 10 — Add/Remove Programs Registry Entry

```go
const uninstallKey = `SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\MyApp`

func writeUninstallRegistry(installDir, appPort, installerExe, version string) {
    uninstallCmd := fmt.Sprintf(`"%s" --uninstall`, installerExe)
    pairs := [][]string{
        {"DisplayName",     "MyApp"},
        {"DisplayVersion",  version},
        {"Publisher",       "MyCompany"},
        {"InstallLocation", installDir},
        {"UninstallString", uninstallCmd},
        {"QuietUninstallString", uninstallCmd},
        {"URLInfoAbout",    "https://myapp.example.com"},
        {"NoModify",        "1"},
    }
    for _, p := range pairs {
        t := "REG_SZ"
        if p[0] == "NoModify" { t = "REG_DWORD" }
        exec.Command("reg", "add", `HKLM\`+uninstallKey, "/v", p[0], "/t", t, "/d", p[1], "/f").Run()
    }
}
```

## Complete Install Step Sequence (Reference)

```
Step 1:  Create install directory + subdirs (logs, storage, tools)
Step 2:  Install PostgreSQL
         → findPsql() — skip if already installed
         → installViaWinget("PostgreSQL.PostgreSQL.15") — try first
         → installPostgresDirect() — fallback (~350 MB download, HTTP/1.1)
Step 3:  Install Node.js
         → findNode() — skip if already installed
         → installViaWinget("OpenJS.NodeJS.LTS") — try first
         → installNodeJSDirect() — fallback (~30 MB MSI, HTTP/1.1)
Step 4:  Extract app bundle
         → len(embeddedWindowsBundle) > 0 → write to tmp, extractZip → done
         → (sidecar zip next to exe → use it — optional dev fallback)
         → GitHub releases API → download
Step 5:  npm install --omit=dev (in install dir)
Step 6:  Setup PostgreSQL database
         → CREATE USER ... WITH PASSWORD ...
         → CREATE DATABASE ... OWNER ...
         → GRANT ALL PRIVILEGES ...
Step 7:  Write .env file (absolute paths, generated secrets)
Step 8:  Run SQL migrations (NUMERICALLY SORTED — V1→V2→...→VN)
Step 9:  Register Windows services via WinSW
Step 10: Health check (poll /health for up to 120s)
Step 11: Write Add/Remove Programs registry entry
```

## Common Errors and Their Fixes

| Error | Cause | Fix |
|---|---|---|
| `GitHub API returned HTTP 404` | No GitHub release published yet | Use embedded bundle (`-tags embedded`) or sidecar zip |
| `stream error: INTERNAL_ERROR; received from peer` | HTTP/2 CDN drops large downloads | Force HTTP/1.1 via `TLSNextProto: make(map[string]func...)` |
| `column X does not exist` after fresh install | Migrations ran in alphabetical not numeric order | Sort by extracted integer version number |
| `go.mod requires go >= X (running go Y)` | Docker image version mismatch | Check `go.mod` first line, use matching `golang:X.Y-alpine` |
| `$n: ... Invalid variable reference` | PS5.1 treats `$n:` as PSDrive | Use `${n}` braces |
| `NativeCommandError` on `docker info 2>&1` | PS5.1 wraps native stderr as ErrorRecord | Use `try { docker info > $null } catch {}` |
| Migrations fail silently on fresh install | Wrong sort order: V100 < V10 < V1 alphabetically | Extract integer, `sort.Slice` numerically |
| App can't find schema/asset files | Relative path breaks when service changes working dir | Write absolute path to `.env`, read with `os.Getenv` |
| Uninstall leaves orphaned database | Old uninstall only removed files | `pg_terminate_backend` + `DROP DATABASE` + `DROP USER` |

## Quick Checklist for a New App (ezLISense or any Node.js + PostgreSQL app)

- [ ] Create `installer/` directory with the file structure above
- [ ] Copy/adapt `bundle_windows_embed.go` and `bundle_windows_noembed.go` (just change package name)
- [ ] Copy/adapt `extract.go` (generic — no app-specific code)
- [ ] Adapt `standalone_windows.go`:
  - [ ] Change service names, install dir, DB name, DB user
  - [ ] Add any app-specific large dirs to the download/skip logic
  - [ ] Set any app-specific env vars in `writeEnvFile()`
  - [ ] Adjust migration dir path if different from `database/migrations/`
- [ ] Create `build-windows-release.ps1` with `-SkipGoCompile` flag
- [ ] Add `installer/assets/bundle-windows.zip` to `.gitignore`
- [ ] Do one full build to populate `dist/go-api-windows-amd64.exe` cache
- [ ] Verify: uninstall → fresh install → app works end-to-end
