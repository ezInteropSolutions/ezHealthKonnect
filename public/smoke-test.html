System Smoke Test

End-to-end connectivity check. Creates temporary test interfaces, sends real messages, then removes all test data.

This test automatically sets up four temporary interfaces (ADT MLLP on port 6620, ORU MLLP on port 6621, FHIR HTTP on port 8091, and HL7-to-File on port 6622), sends test messages through each one, verifies they land in the database, then deletes everything when done. No manual setup required. The full run takes about 30–60 seconds.
