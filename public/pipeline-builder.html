Pipeline Builder — Quick Guide

What is a pipeline?

A pipeline is a sequence of steps that process each incoming message — receive it, transform it, enrich it, and deliver it. Steps execute in the order shown in the flowchart.

Basic interactions

Drag a component from the left panel onto the canvas to add it
Click a step to open its properties on the right
Connect Mode — click step A then step B to draw an arrow
Auto Layout — arranges steps top-to-bottom automatically
Delete — select a step, then press Delete or use the toolbar

Step sequence numbers

Every step has a sequence number that controls execution order:

5 — Inbound connector (receive)
10–59 — Pre-processing, validation
60–99 — Core transform (HL7→FHIR)
100–290 — Enrichment, routing, masking
295 — Outbound connector (deliver)
Same seq → steps run in parallel

Keyboard shortcuts

Ctrl+S Save pipeline
Ctrl+L Lock / unlock zoom
Delete Remove selected step
Scroll Zoom in / out

Tip: Click any step and use the Documentation tab in the properties panel for step-specific reference, examples, and config options.
