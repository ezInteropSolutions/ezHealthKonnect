Reports

12 built-in reports for operations, compliance, and performance — plus a self-service ad-hoc builder

The gallery contains 12 system reports designed by the ezHealthKonnect team. They are read-only and always available.

Workflow

  • Find a report relevant to your question and click Run — results open instantly in the Ad-hoc Builder tab.
  • Each card shows the report's purpose and a pink value box explaining what insight it gives you and when to use it.
  • Want to tweak the time range or dimension? After running, switch to the Ad-hoc Builder tab and adjust filters, then click Run Report.
  • Happy with a custom configuration? Click Save Report to persist it under My Saved Reports.

Report categories

  • Message Flow — volume, status, and type distribution of HL7 messages
  • Pipeline Performance — execution times, error rates, and bottleneck steps
  • HIPAA & Compliance — PHI access audit and data masking coverage
  • Connector Activity — inbound/outbound connector run history
  • Dead Letter Queue — failed messages that need manual review
  • User Activity — login events, config changes, and risk actions

Step 1 — Choose a Data Source

  • Message Flow — queries all interface message tables. Best for: volume trends, status breakdowns, message type distribution.
  • Pipeline Performance — queries transformation_executions and step_executions. Best for: identifying slow steps, success rates, p95 latency.
  • HIPAA Audit — queries pipeline_step_audit. Best for: compliance reports, PHI field access, masking coverage.
  • Connector Activity — queries connectivity_execution_log. Best for: connector reliability, messages retrieved per run.
  • DLQ Analysis — queries dead_letter_queue. Best for: finding recurring failure patterns and unresolved messages.
  • User Activity — queries audit_logs. Best for: security audits, change history, high-risk action tracking.

Step 2 — Dimension (Group By)

  • day / hour / week — time-bucketed trends. Use for line or bar charts showing volume over time.
  • interface — one row per integration interface. Great for comparing interfaces side-by-side.
  • message_type — splits by HL7 event type (ADT^A01, ORU^R01 …). Shows your message mix.
  • status — groups by processed / failed / queued. Use with pie/donut for status distribution.
  • step_type — Pipeline Performance only. Ranks steps by failure count or duration.

Step 3 — Metrics

Select the columns you want in the result. All metrics are pre-checked based on your data source. Uncheck any you don't need.

Step 4 — Time Range

Preset shortcuts: 24h (last 24 hours), 7d (7 days), 30d (30 days), 90d (quarter). All ranges are relative to now.

Step 5 — Visualization

  • Bar Chart — best for comparing values across categories (interfaces, step types).
  • Line Chart — same rendering as bar, ideal for time-series (day/hour dimensions).
  • Pie / Donut — best for proportional breakdowns (status, message type mix).
  • Table — raw tabular output. Ideal for audit exports and drill-down.
  • Metric Cards — highlights scalar KPIs from the first result row. Best for executive summaries.

Result Limit

Controls the maximum rows returned. Keep low (100–500) for UI responsiveness. Maximum allowed is 10,000 rows.
